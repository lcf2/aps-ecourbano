# Eco Urbano

Aplicação mobile desenvolvida para o projeto acadêmico **Eco Urbano**, com foco no registro e visualização de ocorrências ambientais em áreas urbanas.

## Tecnologias

- React Native
- Expo
- TypeScript
- Supabase
- PostgreSQL
- Open-Meteo
- Serviço de mapas
- Git e GitHub

O desenvolvimento foi iniciado no **Kiro** e posteriormente migrado para o **Visual Studio Code**, utilizando o **Ollama** como apoio durante a programação.

## Funcionalidades

- Cadastro e visualização de ocorrências ambientais
- Localização das ocorrências
- Visualização por meio de mapas
- Consulta de informações meteorológicas
- Consulta de informações relacionadas à qualidade do ar
- Autenticação de usuários
- Armazenamento de dados utilizando Supabase

## Como executar

### Requisitos

- Node.js
- npm
- Expo
- Git
- Android Studio ou Expo Go para testes em Android

### Instalação

Clone o repositório e entre na pasta do projeto:

```bash
git clone URL_DO_REPOSITORIO
cd eco-urbano
```

Instale as dependências:

```bash
npm install
```

Inicie o projeto:

```bash
npx expo start
```

A aplicação pode ser executada pelo Expo Go, emulador Android ou ambiente iOS compatível.

## Configuração

O projeto utiliza o Supabase e serviços externos. As informações de acesso devem ser configuradas por meio de variáveis de ambiente.

Não devem ser adicionadas ao GitHub chaves, senhas ou outras informações privadas.

## Testes

A aplicação foi executada e testada em ambiente Android e iOS durante o desenvolvimento.

## Projeto acadêmico

Projeto desenvolvido para aplicação prática dos conhecimentos de desenvolvimento mobile, banco de dados, APIs e integração de serviços.
